Para programar en JavaScript hara uso de sus conocimiento de programacion (basica / intermedia/ avanzada)
Variables: locales, globales, estaticas/constantes
Estructuras de control (if/else)
Bucles (for, while)
Funciones (declaracion, expresion, flecha)

Tipos de variables

  • let: locales - dentro de una funcion o bloque
  • var: globales - las podemos usar en cualqueir parte del desarrollo
  • const: son variables con valores fijos, que no pueden cambiar de valor durante su ejecusion

Tipos de datos

  • String: caracteres alfanumericos
  • number: valores numericos
  • Booleano: t/f
  • Arrays: listas (Elementos )
  • Objects: Diccionarios
  • Null - Valor indefinido

programacion jAVASCRIPT

  • Condiciones: if/else
  • Estructura: Switch
  • for.. of - para recorrer colecciones (arrays)
  • for..in - para recorrer object/dicc (clave)

momento - lugar cuando se ejecuta JS

  • Script dentro del HTML - script enbebido en medio del HTML - (INLIEN SCRIPT EARLY)
  • Script dentro de un control - Uso de los atributos en elementos HTML - (INLIEN EVENTOS HANDLER)
  • Script al final (antes de cerrar el body) - Script enbebido al final antes del body
  • Archivo externo (.js) - vinculado al HTML - (Extrenal Script)

Eventsos de JAVASCRIPT para paginas web
Tarea Final: implementar un ejemplo para cada evento enlistado
  • load

    Definicion: El evento que se dispara cuando toda la página ha terminado de cargar completamente, incluyendo imágenes, estilos y scripts.
    Este evento sirve para: Ejecutar código cuando todos los recursos de la página están listos.
    Funciona como: Un indicador de que la página está completamente cargada y lista para interactuar.
    Se hace: window.addEventListener('load', function() { /* código */ });
    No se hace: Confundirlo con DOMContentLoaded (que se dispara antes, solo cuando el HTML está parseado).

  • unload

    Definicion: El evento que se dispara cuando el usuario está a punto de abandonar la página.
    Este evento sirve para: Realizar acciones de limpieza cuando el usuario sale de la página.
    Funciona como: Una notificación de que el usuario está dejando la página actual.
    Se hace: window.addEventListener('unload', function() { /* limpieza */ });
    No se hace: Intentar prevenir que el usuario salga de la página o mostrar alertas (no es confiable en navegadores modernos).

  • beforeunload

    Definicion: El evento que se dispara justo antes de que la página se descargue, permitiendo advertir al usuario.
    Este evento sirve para: Mostrar una confirmación antes de que el usuario abandone la página con cambios sin guardar.
    Funciona como: Un punto de confirmación antes de cerrar o recargar la página.
    Se hace: window.addEventListener('beforeunload', function(e) { e.preventDefault(); e.returnValue = ''; });
    No se hace: Personalizar el mensaje (los navegadores modernos usan mensajes predeterminados por seguridad).

  • visibilitychange

    Definicion: El evento que se dispara cuando la pestaña o ventana del navegador cambia entre visible y oculta.
    Este evento sirve para: Detectar cuando el usuario cambia de pestaña o minimiza el navegador.
    Funciona como: Un interruptor que notifica cambios en la visibilidad de la página.
    Se hace: document.addEventListener('visibilitychange', function() { if(document.hidden) { /* pausar */ } });
    No se hace: Usarlo para rastrear usuarios de forma invasiva o para bloquear funcionalidad cuando la pestaña está oculta.

  • readystatechange

    Definicion: El evento que se dispara cuando el estado de carga del documento cambia (loading, interactive, complete).
    Este evento sirve para: Monitorear las diferentes etapas de carga del documento.
    Funciona como: Un indicador del progreso de carga del documento con tres estados posibles.
    Se hace: document.addEventListener('readystatechange', function() { console.log(document.readyState); });
    No se hace: Usarlo en lugar de DOMContentLoaded o load para casos simples (es más complejo de lo necesario).

  • selectionchange + fullscreenchange + fullscreenerror

    Definicion: Eventos relacionados con la selección de texto, cambios de pantalla completa y errores de pantalla completa.
    Este evento sirve para: selectionchange detecta cuando cambia el texto seleccionado; fullscreenchange detecta entrada/salida de pantalla completa; fullscreenerror detecta errores al intentar pantalla completa.
    Funciona como: Notificadores de cambios en la selección del usuario y en el modo de visualización.
    Se hace: document.addEventListener('selectionchange', function() { /* código */ }); document.addEventListener('fullscreenchange', function() { /* código */ });
    No se hace: Abusar de selectionchange (se dispara frecuentemente), ni forzar pantalla completa sin interacción del usuario.

  • copy, cut, paste

    Definicion: Eventos que se disparan cuando el usuario copia, corta o pega contenido en la página.
    Este evento sirve para: Interceptar y modificar operaciones de portapapeles o agregar funcionalidad personalizada.
    Funciona como: Interceptores de las acciones del portapapeles del usuario.
    Se hace: document.addEventListener('copy', function(e) { e.clipboardData.setData('text/plain', 'texto personalizado'); e.preventDefault(); });
    No se hace: Bloquear completamente estas acciones (frustra a los usuarios) o robar información del portapapeles sin consentimiento.

  • pointerlockchange

    Definicion: El evento que se dispara cuando el cursor del mouse es bloqueado o desbloqueado en un elemento.
    Este evento sirve para: Detectar cambios en el bloqueo del puntero, útil para juegos y aplicaciones 3D.
    Funciona como: Un notificador de cuando se activa o desactiva el control total del mouse.
    Se hace: document.addEventListener('pointerlockchange', function() { if(document.pointerLockElement) { /* bloqueado */ } });
    No se hace: Bloquear el puntero sin una clara indicación al usuario o sin proporcionar una forma fácil de salir.

  • scroll

    Definicion: El evento que se dispara cuando el usuario desplaza la página o un elemento con scroll.
    Este evento sirve para: Detectar el desplazamiento y ejecutar acciones como cargar más contenido o mostrar/ocultar elementos.
    Funciona como: Un detector continuo de movimiento de scroll que se dispara múltiples veces.
    Se hace: document.addEventListener('scroll', function() { /* código con throttling/debouncing */ });
    No se hace: Ejecutar operaciones pesadas sin optimización (usar throttle o debounce), ya que se dispara muy frecuentemente.
