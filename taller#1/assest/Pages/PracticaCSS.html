Practica de CSS

CSS nos ayuda/sirve para dar estilo y diseño a nuestra Pagina Web.

Para aplicarlo tenemos tres opciones:
1.-En linea - Código embebido

Línea de estilo con Código embebido



2.-Código Interno - Código en la cabecera
El código debe ir en la cabecera del file

3.-Externo - File.css

Notas:

1.-Siempre se ejecuta de arriba hacia abajo, es decir la misma etiqueta la puede escribir dos veces y va a valer la ultima

2.-Tener cuidado con montar las etiquetas en el diseño

3.-Valide resetear antes de aplicar su diseño
